# Quick Hardware Test (hwtest_gui.py)
#
# No third-party Python packages are required.
# The script only uses the Python 3 standard library (including tkinter).
#
# --- System packages (install with apt, not pip) ---
#   sudo apt install python3 python3-tk     # Python + Tkinter (required)
#   sudo apt install ffmpeg                 # webcam preview + MP3 speaker test
#   sudo apt install alsa-utils             # aplay, for the speaker test
#   sudo apt install usbutils               # lsusb, for the USB devices check
#
# --- Optional: only if you want to build a standalone executable ---
# The script detects frozen builds (sys.frozen), so it works with PyInstaller.
